Set up once

Connect Brrtz in about a minute.

  1. 1

    Open ChatGPT on the web

    Go to Settings → Plugins or Apps. Turn on Developer mode if ChatGPT asks.

  2. 2

    Create the Brrtz app

    Name it Brrtz Gear Radar, choose No Auth, and use this server URL:

    https://brrtz.com/mcp
  3. 3

    Start a new chat

    Select Brrtz Gear Radar from the + menu, then ask for the gear you want.
